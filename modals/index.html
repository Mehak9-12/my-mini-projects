A modal is a pop-up window that appears on top of a web page to grab the user's attention. It is typically used for alerts, forms, or important messages. When a modal is open, user interaction with the rest of the page is blocked. An overlay is a semi-transparent or blurred layer that appears behind the modal. Its purpose is to dim or blur the background, making the modal more prominent and preventing interaction with the rest of the page. The Escape (ESC) key is commonly used to close modals.
